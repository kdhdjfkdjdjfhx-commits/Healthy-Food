# HealthyFood Pro v3

نسخة Android Native عربية مهيأة للبناء السحابي بواسطة GitHub Actions.

## المزايا
- واجهة عربية حديثة
- صفحة رئيسية وبطاقات تقدم
- رسم بياني أسبوعي تجريبي للتقدم
- قاعدة أطعمة وبحث
- خطة غذائية يومية إرشادية
- أهداف السعرات والبروتين والكربوهيدرات والدهون والماء
- حاسبة BMI والسعرات التقريبية
- وضع ليلي
- بناء APK تلقائي من GitHub Actions

## بناء APK من الهاتف
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع جميع ملفات المشروع إلى المستودع.
3. افتح Actions.
4. شغّل workflow باسم Build HealthyFood APK.
5. بعد نجاح البناء، نزّل Artifact باسم HealthyFood-Pro-v3-debug.
6. فك الضغط وثبّت app-debug.apk.

## ملاحظة صحية
الأرقام والحسابات الغذائية تقديرية وليست تشخيصًا أو نصيحة طبية.
